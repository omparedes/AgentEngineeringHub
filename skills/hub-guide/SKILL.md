# Usar Agent Engineering Hub

1. **Identifica el entorno.** Usa la superficie y el directorio de trabajo que indica el cliente. Si no puedes distinguir Codex de Antigravity App, pregunta sólo si cambia la recomendación o el destino. Comprueba permisos y disponibilidad de Git, Python y las herramientas que afecten a la tarea sin ejecutar instaladores. Usa resultados del cliente, manifiestos, lockfiles y nombres en selectores o rutas de skills legibles. Distingue una dependencia declarada de una instalación confirmada, un servidor configurado de uno activo, y una comprobación que quedó bloqueada. Evita valores de credenciales.
2. **Localiza el Hub.** Usa el checkout indicado para el proyecto, uno ya identificado en la conversación o el archivo `hub-source.json` junto a esta skill instalada por el Hub. Ese archivo sólo orienta la búsqueda. Comprueba que el checkout contiene `catalog/`, `profiles/` y una referencia reconocible. Si Git está disponible, identifica el commit y la etiqueta exacta si existe. Para un ZIP revisado, usa la referencia de origen aportada por la persona. Expón si la versión no pudo comprobarse.
3. **Selecciona la operación.**
   - **Preparar mi equipo.** Resume cliente, permisos, dependencias disponibles, herramientas reutilizables y acceso al catálogo. Si sólo tienes la URL oficial, propón obtener la última referencia estable aprobada en el repositorio oficial. Indica el destino y confirma antes de clonar, instalar o configurar. Si faltan Git o Python, ofrece obtener el ZIP oficial de la revisión elegida, leer la documentación local o preparar Python en el Hub si se necesita la CLI. Si la edición estable aún carece de esta skill, aplica su guía de agentes disponible y ofrece una revisión posterior sólo como ensayo explícito.
   - **Iniciar un proyecto.** Lee las instrucciones y los archivos mínimos del proyecto. Completa sólo las incógnitas que cambien la propuesta: etapa, objetivo de negocio, usuarios, stack y restricciones. Aplica `project-bootstrap` si está disponible. En un trabajo empresarial con reglas abiertas, sugiere `domain-discovery` y un primer resultado de Domain-First Agile Engineering. En una tarea pequeña, delimita un incremento y añade un boceto sólo si hay una decisión de interfaz.
   - **Continuar o revisar.** Lee las instrucciones, los manifiestos y las decisiones existentes antes de preguntar. Resume qué cambió desde el último análisis, qué se puede reutilizar y qué falta para este trabajo. Usa `change-impact-analysis` si cambia un contrato o datos ya usados. Reserva `hub-maintainer` para revisar una ficha o evidencia upstream. Recalcula la selección cuando cambien la fase, el stack, los permisos o el objetivo. Conserva las decisiones del proyecto en sus propios documentos.
4. **Consulta sólo lo pertinente.** En el checkout revisado usa `python scripts/hub.py profiles` si todavía no conoces el perfil. Ejecuta `python scripts/hub.py recommend PERFIL --agent AGENTE`, con condiciones sustentadas por los archivos o la petición. Inspecciona con `show ID` sólo las fichas que cambian la decisión. Si faltan Python o las bibliotecas del Hub, lee el perfil pertinente y sus fichas. Para ese camino, recomienda sólo capacidades cuya condición, agente, stack y dependencias puedas comprobar localmente. Si falta acceso al catálogo, entrega el inventario y deja las recomendaciones específicas pendientes. Usa el checkout local en consultas cotidianas.
5. **Entrega el plan.** Indica la revisión, lo ya instalado o declarado, el mínimo disponible, lo opcional y lo incompatible que afecte al trabajo. Para cada incorporación justifica su utilidad, requisitos, alcance y cómo comprobarla. La instalación global de `hub-guide` es optativa. Para capacidades del proyecto, prioriza alcance local, permisos mínimos y reutilización. Ofrece el siguiente paso verificable y pide autorización específica antes de modificar archivos, instalar dependencias, habilitar MCP o cambiar configuración. Si se autoriza alguna operación, actúa sólo dentro de ese alcance.

La URL oficial es `https://github.com/omparedes/AgentEngineeringHub`. El checkout incluye `docs/guia-hub.md` con el procedimiento de instalación, sus previsualizaciones y las instrucciones de actualización y retiro.
