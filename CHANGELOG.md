# Historial

## 0.2.0

- Consolidación de Modern Web Guidance y de las fichas de Next.js DevTools, axe-core + Playwright, Lighthouse CI, OWASP ASVS, Sentry, Filesystem y Figma. Se amplían seis fichas MCP existentes y se conserva la selección contextual.
- Domain-First Agile Engineering incorpora un recorrido adaptable, plantillas y ejemplos ficticios. `project-bootstrap` propone una variante y el siguiente resultado verificable. `domain-discovery` explicita la participación de quienes deciden y operan.
- Google Stitch se añade como herramienta opcional de prototipado. La ficha de Figma distingue capacidades remotas y locales y enlaza las skills del proveedor.
- El perfil Angular con Supabase condiciona `angular-skills` al trabajo de interfaz. Una consulta exclusivamente SQL puede mantener una selección centrada en datos.
- `hub-guide` presenta un informe para elegir, posponer u omitir herramientas. Guarda las decisiones del proyecto separadas del estado observado. `tools-plan` consulta esas decisiones sin escribir y el instalador de la skill previsualiza y fija el SHA que se va a copiar.
- El inventario consolidado contiene 29 capacidades, cinco perfiles y cinco skills propias. El [informe de versión](docs/informe-0.2.0.md) registra los escenarios aceptados, la validación y el requisito de CI alojada.

## 0.1.0 · 19 de noviembre de 2026

Primera base local de la biblioteca. Se registraron 14 capacidades externas con referencias Git y fuentes primarias, cuatro skills originales y dos workflows. Cinco perfiles permiten obtener propuestas locales y explicar exclusiones.

Los contratos YAML/JSON y el frontmatter se validan con la CLI y unittest. Se incorpora CI de validación de PR y el proceso de revisión documental. Las integraciones MCP quedan pendientes de prueba funcional en cada cliente. La fecha corresponde a la implementación local.
